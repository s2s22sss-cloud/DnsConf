# Документация DNS Block&Redirect Configurer

Утилита загружает hosts-файлы по ссылкам и переносит из них правила
**блокировки** и **перенаправления** доменов в аккаунт **Cloudflare Zero Trust**
или **NextDNS**. Обычно её запускают по расписанию через GitHub Actions.

Краткое описание проекта — в [README.ru.md](../README.ru.md). Эта папка содержит
подробную документацию.
