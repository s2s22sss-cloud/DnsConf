# Ведение документации

## Принципы

- **Язык** — русский. Корневой `README.md` — краткий англоязычный вход,
  `README.ru.md` — краткий русский; подробности живут только в `docs/`.
- **Формат** — Markdown, который GitHub отображает без сборки. Схемы — Mermaid
  в блоках ` ```mermaid `.
- **Одна тема — одно место.** Если факт описан на одной странице, на других
  ставится ссылка, а не копия.
- **Документация описывает фактическое поведение кода.** Если поведение
  считается ошибкой, оно описывается как есть и дублируется в
  [known-issues.md](../known-issues.md).
- Ключи, токены и ID в примерах — только вымышленные.

## Структура

```
docs/
├── README.md            оглавление — точка входа
├── known-issues.md      известные ошибки и ограничения
├── user/                для тех, кто настраивает и запускает
└── dev/                 для тех, кто меняет код
```

## Что обновлять при изменении кода

| Изменение | Страницы |
|---|---|
| Новая или изменённая переменная окружения | `user/configuration.md`, `user/quick-start.md`, оба README |
| Правила разбора hosts (`data_sources/*`) | `user/data-sources.md`, `dev/architecture.md` (конвейер) |
| Логика Cloudflare (`dns/cloudflare/**`) | `user/cloudflare.md`, `dev/architecture.md`, `dev/api-reference.md` |
| Логика NextDNS (`dns/next_dns/**`) | `user/nextdns.md`, `dev/architecture.md`, `dev/api-reference.md` |
| Сообщения об ошибках, коды выхода | `user/troubleshooting.md` |
| Версия Java, зависимости, `pom.xml` | `dev/development.md`, `user/local-run.md` |
| Расписание, окружение в workflow | `user/quick-start.md`, `dev/development.md` (CI) |
| Новый провайдер | см. [adding-provider.md](adding-provider.md#6-документация) |
| Исправлена ошибка из known-issues | удалить пункт из `known-issues.md` и поправить ссылки на него |

## Шаблон страницы

```markdown
# Заголовок

Одно-два предложения: что это и кому нужно.

## Раздел

Текст, таблицы, примеры.

## Ошибки / что важно знать   ← если применимо
```

## Проверка перед коммитом

- Все относительные ссылки открываются (в том числе якоря `#...`).
  Якорь GitHub — заголовок в нижнем регистре, пробелы заменены на `-`,
  знаки препинания удалены.
- Пример команд действительно работает.
- Новая страница добавлена в [docs/README.md](../README.md).
