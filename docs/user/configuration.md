# Переменные окружения

Вся настройка — через переменные окружения. Они читаются один раз при старте
(`com.novibe.common.config.EnvironmentVariables`).

| Переменная | Обязательна | Где хранить в GitHub | Значение |
|---|---|---|---|
| `DNS` | да | Variables | `Cloudflare` или `NextDNS`, регистр не важен |
| `CLIENT_ID` | да | **Secrets** | Cloudflare: Account ID. NextDNS: ID профиля |
| `AUTH_SECRET` | да | **Secrets** | Cloudflare: API-токен. NextDNS: API-ключ |
| `REDIRECT` | нет | Variables | Ссылки на hosts-файлы для перенаправлений, через запятую |
| `BLOCK` | нет | Variables | Ссылки на hosts-файлы для блокировок, через запятую |

Если обязательная переменная не задана или пустая, скрипт пишет
`Не обнаружена обязательная переменная среды: <ИМЯ>` и завершается с кодом 1.
Неизвестное значение `DNS` даёт `Unsupported DNS provider!` и тоже код 1.

## Формат списков `REDIRECT` и `BLOCK`

```
https://first.example/hosts,https://second.example/hosts
```

- Разделитель — запятая. Пробелы вокруг запятых **не обрезаются**: ссылка
  с пробелом в начале сломает запуск (см. [Известные проблемы](../known-issues.md)).
- Порядок важен для `REDIRECT`: если домен встречается в нескольких источниках,
  берётся IP из **первого** источника.
- Пустое значение и отсутствие переменной равнозначны.

## Что делают пустые `REDIRECT` / `BLOCK`

| `BLOCK` | `REDIRECT` | Cloudflare | NextDNS |
|---|---|---|---|
| задан | задан | Пересоздаёт и блокировки, и перенаправления | Дополняет denylist и rewrites |
| задан | пусто | Пересоздаёт блокировки, **удаляет** свои перенаправления | Дополняет denylist, rewrites не трогает |
| пусто | задан | Пересоздаёт перенаправления, **удаляет** свои блокировки | Дополняет rewrites, denylist не трогает |
| пусто | пусто | **Удаляет** все свои списки и правила | **Удаляет весь** denylist и все rewrites профиля, включая добавленные вручную |

Подробности: [Cloudflare](cloudflare.md#поведение-скрипта),
[NextDNS](nextdns.md#поведение-скрипта).
